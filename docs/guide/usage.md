# 使用手册

## 上传页（`/`）

首页受登录中间件保护，需先登录。

1. 点击「上传目录」选择或输入目标目录（支持联想已有目录；留空则按类型自动归类）。
2. 拖拽、选择文件，或粘贴图片/文件。
3. 上传成功后可一键复制多种链接格式。

约束：

- 未登录禁止上传（接口校验会话 Cookie）
- 单文件 ≤ 20MB（可由 `MAX_UPLOAD_BYTES` 调整）
- HEIC、TIFF 会在客户端转为 WebP 或 JPEG，便于浏览器预览

## 登录与初始化（`/login`）

- **首次使用**：系统无用户时，可「首次初始化」创建顶级管理员。
- **之后**：仅管理员可在后台创建其他账号；用户用用户名密码登录。

## 管理后台（`/admin`）

| 页面 | 功能 |
|------|------|
| 文件库 | 分页列表、搜索筛选、预览、改名、改目录、删除 |
| 批量操作 | 批量删除、批量移动目录 |
| 用户 | 管理员维护账号 |
| 状态 | 空间占用百分比、类型/目录分布、近 24 小时 / 7 日 / 30 日上传、运行绑定 |

## 链接格式

复制菜单通常包含：

- 原始直链（R2 公网 URL）
- Markdown
- HTML `<img>`
- BBCode

直链域名取决于你配置的 `R2_PUBLIC_BASE_URL`。

## 客户端 / API

`POST /api/upload` 需要有效登录会话（`credentials: include`）。第三方图床客户端若无法携带 Cookie，可二开补 API Token（schema 已预留 `api_tokens`）。CORS 见 [配置说明](./configuration)。
